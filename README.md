# kgu-fcr-task

Задание 01: многостраничный сайт-анкета под мобильное устройство (430×932).

Тема: анкета для вступления в кибертеррористическую ячейку «ШУМ».

- `index.html` — главная: описание ячейки и анкеты
- `form.html` — анкета кандидата (все основные типы инпутов, submit/reset)
- `profile.html` — профиль: те же поля, фото, блок смены пароля

Стили — `css/style.css`, картинки — `img/`. Открыть любой файл в браузере.
