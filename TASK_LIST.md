# Список заданий

1. **`task/HC-01`** — CSS-переменные и тёмная тема: вынести цвета в переменные и добавить тёмную тему.
 *Технологии:* HTML, CSS (custom properties, `:checked`)

2. **`task/HC-02`** — Вёрстка 3D-карточки: собрать `index.html` под готовый `style.css`.
 *Технологии:* HTML, CSS (3D-трансформации)

3. **`task/HC-04`** — Игры по CSS: Flexbox Froggy (24 уровня) и Grid Garden (28 уровней), практика `flexbox` и `grid` со скриншотами результата.
 *Технологии:* CSS (flexbox, grid)

4. **`task/JS-01`** — Базовые задачи по JavaScript (`required.js` / `optional.js`) с прогоном тестов.
 *Технологии:* JavaScript, Node.js v24.21.0, `node:test`

5. **`task/TS-02`** — Девять упражнений по TypeScript: интерфейсы, union/narrowing, дженерики, классы и модификаторы доступа; типизация через `typecheck`.
*Технологии:* TypeScript 7, `tsc`, Node.js v24.21.0

6. **`task/CAT-01`**, **`task/CAT-01-demo`** — Асинхронная загрузка данных из публичного API и минимальный UI.
 *Технологии:* TypeScript, esbuild, `fetch`/`async-await`, npm, Node.js v24.21.0

7. **`task/RE-01`** — Перевести приложение «Мой IP» (из CAT-01) на React: JSX-компоненты, рендер через `createRoot`, CSS-модули и сборка через webpack.
*Технологии:* React, TypeScript, JSX, CSS-модули, webpack, npm

> Ветки `*-demo` — это готовые шаблоны-заготовки для соответствующих заданий.
