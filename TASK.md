# 01. Задание

### Многостраничный сайт с анкетой и формой

Создайте сайт-анкету на свободную тему, это может быть: форма на вступление в книжный клуб, профиль персонажа D&D, анкета для попадания на какое-нибудь мероприятие и тд

Сайт должен быть адаптивным: используйте `@media`-запросы, верстайте **mobile-first**.
Брейкпоинт для десктопа — от **769px**.

Нужно реализовать три страницы:

1. Главная (Main/Home)
2. Анкета/профиль пользователя
3. Форма запонления анкеты/профиля пользователя

Все страницы должны содержать **хедер**, **футер**, **навигацию**.

- **Хедер** должен содержать логотип (найдите и вставьте любую картинку)
- Страницы должны содержать **favicon**
- **Футер** обычно также содержит логотип и навигацию, любую контактную информацию
- **Навигацию** можно реализовать как угодно, либо какая-то навигационная панель либо переходы с главной на другие страницы по нажатию на какой-либо элемент

---

#### Главная страница

> Содержит описание нашей анкеты, чему данная анкета посвящена и так далее. Может содержать фото, видео, тексты все на ваше усмотрение и творчество

#### Форма/анкета

Форма должна содержать все основные инпуты:

- Обычный текстовый (Имя, Прозвище, любимое слово в английском и тд)
- Email
- Пароль (password)
- Число (Кол-во прочитанных за лето книг, возраст, счастливое число)
- Дата (день рождения, дата поступления и тд)
- Select (любой список)
- Radio кнопка 2-3 варианта на выбор
- Checkbox (согласие на обработку данных и тд)
- Textarea (немного о себе, несмешной анекдот и тд)
- Кнопки submit и reset

**Должно получиться минимум 10 инпутов**

#### Профиль/анкета

- Профиль содержит все те же поля, что и анкета
- В профиле есть фото юзера
- В профиле есть блок с изменением пароля
  - (Поля: введите пароль, введите новый пароль, повторите новый пароль)

*Используйте CSS для стилизации интерфейса, жестких ограничений и требований нет*

### Полезные команды git

Добавьте мой реп как ремоут дял получения заданий:

```bash
git remote add upstream https://github.com/MisaSup/skfu-mcr-task
```

Проверка:

```bash
git remote -v
```

Перейдитена ветку с заданием:

```bash
git switch task/01
```

Создайте ветку:

```bash
git switch -c student/01-{ВАША ФАМИЛИЯ ИО [gorelovma]}
```

В ходе работы делайте осмысленные коммиты и придерживайтесь формы сообщения:

```
student/01: your commit message
```
