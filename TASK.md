# HC-04. Игры по CSS: Flexbox Froggy и Grid Garden

Практика по CSS. Закрепляем `flexbox` и `grid` в игровой форме.

## Цель

Научиться:

- выравнивать элементы по осям (`justify-content`, `align-items`, `align-content`);
- управлять направлением, порядком и переносом элементов (`flex-direction`, `flex-wrap`, `order`);
- расставлять элементы по сетке (`grid-template-columns/rows`, `grid-column`, `grid-row`, `grid-area`).

## Что нужно сделать

1. Пройти [Flexbox Froggy](https://flexboxfroggy.com/#ru) — **все 24 уровня**.
   Зеркало: [appbrewery.github.io/flexboxfroggy](https://appbrewery.github.io/flexboxfroggy/#ru).
2. Пройти [Grid Garden](https://cssgridgarden.com/#ru) — **все 28 уровней**.
   Зеркало: [appbrewery.github.io/gridgarden](https://appbrewery.github.io/gridgarden/#ru).
3. Сделать **скриншоты финальных экранов** обеих игр.
4. Прислать скриншоты письмом (см. ниже).
