# CAT-01

Мы начинаем разбираться с **асинхронным кодом и загрузкой данных**.

Задача — сделать **простое приложение, которое по нажатию кнопки показывает IP-адрес пользователя**. Данные нужно получить из **бесплатного публичного API** асинхронно (`fetch` + `async/await`).

В качестве примера и шаблона используется **ipify** — сервис, который возвращает IP-адрес клиента. На практике мы разберём его вместе.

> Многие публичные API недоступны из браузера или требуют VPN. Поэтому в качестве примера берём **ipify**: он отдаёт простой JSON и работает без ключа.

## Требования к окружению

Версия ноды, которую я использую — **v24.21.0**.

Проверьте вашу версию:

```bash
node -v
```

Установите нужную версию:

```bash
nvm install 24.21.0
```

## Что нужно сделать

> В ветке `task/CAT-01-demo` лежит готовый шаблон приложения, но написан он на **обычном JavaScript**: кнопка **«Показать мой IP»**, область для результата и сборка через **esbuild**. **TypeScript в шаблоне нет** — его нужно добавить самостоятельно. Если берёте шаблон за основу, установите зависимости командой `npm install` и выполняйте шаги ниже. Если делаете всё с нуля — делайте все шаги.

Что нужно потренировать в этом задании:

- **Манипуляции с DOM**: находить элементы и менять их через методы (`querySelector`, `addEventListener`, `textContent`, `innerHTML`, `classList`).
- **Загрузку данных**: асинхронный запрос через `fetch` + `async/await` в отдельном модуле.
- **Состояния интерфейса**: показать спиннер во время загрузки, IP — при успехе, понятное сообщение — при ошибке.
- **TypeScript**: перевести проект на типы и типизировать компоненты.

1. Инициализировать проект через npm:

   ```bash
   npm init
   ```

2. Установить **TypeScript** и `esbuild`:

   ```bash
   npm install --save-dev typescript esbuild
   ```

3. Инициализировать и настроить `tsconfig.json` (не забудьте про `rootDir`, `outDir` и режим модулей).

4. Перевести проект на **TypeScript**:

   - держать все исходники в `src/**/*.ts`;
   - добавить `src/global.d.ts` с объявлением `declare module "*.css";` (чтобы TypeScript не ругался на импорт стилей);
   - добавить типы компонентов в `src/shared/lib/components/types.ts` — дженерик-тип `Component` с опциональным `children`;
   - типизировать пропсы компонентов, параметры функций и возвращаемые значения.

5. Добавить в `package.json` скрипты сборки, разработки и проверки типов. Собирать будем через **esbuild**:

   ```json
   {
     "scripts": {
       "build": "esbuild src/index.ts --bundle --outfile=dist/index.js --format=esm",
       "dev": "esbuild src/index.ts --bundle --outfile=dist/index.js --format=esm --watch",
       "typecheck": "tsc --noEmit"
     }
   }
   ```

6. Разобраться с API **ipify**. Запрос:

   ```bash
   curl "https://api.ipify.org?format=json"
   ```

   Ответ:

   ```json
   { "ip": "176.52.83.148" }
   ```

   Хотите другой API — берите из [списка публичных бесплатных API](https://github.com/public-apis/public-apis), но тогда учтите ограничения браузера и CORS.

7. Реализовать по клику на кнопку загрузку данных и **три состояния интерфейса**:

   - **DOM**. Обработчик вешаем через `addEventListener`. Элементы ищем через `querySelector`, содержимое меняем через `textContent` / `innerHTML`, а состояние — через `classList`.
   - **Loading**. Пока идёт запрос, вместо IP показываем спиннер — `Spinner()` из `src/shared/ui/Spinner`.
   - **Запрос**. Загрузку выносим в отдельный модуль (например, `src/entities/ip/api/getIpApi.ts`) и получаем данные через `fetch` + `async/await`. Функция возвращает уже разобранные данные (`data.ip`), а не сырой ответ.
   - **Success**. При успехе показываем IP-адрес в области результата.
   - **Error**. Оборачиваем запрос в `try/catch`: если он не удался, показываем понятное сообщение, а не сырой объект ошибки.

8. Стили — **mobile-first**, про десктопные размеры можно не думать.

9. Подход «как в React»: компонент — это функция, которая возвращает строку с HTML. В `index.html` уже есть `<div id="app">`, а `src/index.ts` рендерит в него `App()`.

10. Собрать проект через esbuild и проверить результат в браузере.

## Требования к структуре

Запрос данных выносим в отдельный модуль, а стили держим рядом с компонентами:

```text
index.html
package.json
tsconfig.json
public/
  styles.css
src/
  index.ts
  App.ts
  global.d.ts
  shared/
    lib/
      components/
        types.ts
    ui/
      Spinner/
        Spinner.ts
        Spinner.css
  entities/
    ip/
      api/
        getIpApi.ts
  widgets/
    IpViewer/
      IpViewer.ts
      IpViewer.css
```

## Критерии готовности

- Проект переведён на **TypeScript**: есть `tsconfig.json`, все компоненты в `.ts`, типы подключены.
- По клику на кнопку виден **спиннер**, пока идёт запрос.
- При успехе отображается **IP-адрес**.
- При ошибке — **понятное сообщение**.
- Запрос вынесен в отдельный модуль и использует `fetch` + `async/await`.
- Элементы ищутся через `querySelector`, состояние меняется через `classList` / `textContent`.
