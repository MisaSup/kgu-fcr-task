# HC-02. Вёрстка 3D-карточки

Только HTML и готовый CSS

## Цель

Научиться:

- собирать структуру HTML-документа;
- подключать внешний файл стилей;
- размечать элементы так, чтобы готовые CSS-классы работали.

## Что дано

`style.css` уже готов: в нём описаны все стили 3D-карточки (`.card`, `.card-front`, `.card-back`, переворот при наведении, тени). Нужно написать `index.html` с такой разметкой, чтобы карточка ожила.

## Что нужно сделать

1. Создать файл `index.html`.
2. Добавить базовую структуру документа: `<!DOCTYPE html>`, `<html lang="en">`, `<head>` с `charset`, `viewport` и `title`.
3. Подключить готовый файл стилей style.css
4. Сверстать карточку по структуре ниже.

### Структура

- `.card` — контейнер 3D-сцены. Все остальное внутри него
- `.card-front` — лицевая сторона: аватар, имя, должность.
- `.card-back` — обратная сторона: описание и кнопка.

## Требования

- Классы должны точно совпадать с теми, что используются в `style.css`.
- У картинки обязателен атрибут `alt`.
- JavaScript не используется.
